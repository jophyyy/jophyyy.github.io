# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML5, CSS3 Custom Properties, Vanilla JavaScript (ES6)

## Users

Developer and frontend engineers testing web animations, micro-interactions, layout reflow, and DOM performance benchmarks.

## Product Purpose

A lightweight, dedicated testing server and sandbox environment for evaluating UI animations (terminal bootloader, cursor spotlight tracking, draggable scroll momentum, CLI drawer transitions, and form dispatch tweens) in a real browser.

## Positioning

Zero-dependency, standalone animation sandbox with built-in test diagnostic CLI and native browser performance tracking (~60 FPS).

## Operating Context

Local browser testing and GitHub Pages hosting (`https://jophyyy.github.io`). Used for prototyping motion, testing responsive viewport scaling, and validating clean CSS/JS interaction patterns.

## Capabilities and Constraints

- **Capabilities**:
  - Interactive terminal startup sequence with simulated CLI questions & answers
  - Real-time cursor coordinates and dynamic radial spotlight tracking
  - Click-and-drag horizontal momentum track with velocity scaling
  - Expandable bottom-right CLI drawer console with diagnostic commands (`test`, `reboot`, `status`)
  - Filterable module grid with smooth transitions
  - Form validation and submit feedback simulation
- **Constraints**:
  - Zero external CSS or JS frameworks (no Tailwind, React, or jQuery)
  - Must remain fast, clean, and lightweight (< 16ms frame render budget)
  - Text must remain minimal, direct "Testing" template copy (avoiding fabricated claims or marketing fluff)

## Brand Commitments

- **Name**: Jophy Test Website
- **Tagline**: Testing Server
- **Tone**: Clean, minimalist, modern developer aesthetic (inspired by Linear / Vercel design standards)

## Product Principles

1. **Craft Over Gimmick**: Motion must be purposeful and smooth (60 FPS); avoid distracting fluorescent neons or heavy glowing text shadows.
2. **True Visual Hierarchy**: Use subtle contrast, crisp 1px borders, and clear typography scaling rather than excessive nested containers.
3. **Transparent Testing Context**: Never fabricate credentials, claims, or personal experience; clearly identify the site as an animation and UI testbed.
